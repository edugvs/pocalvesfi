# PocalvesFI

App pessoal de finanças, hospedado via GitHub Pages.

- Frontend: HTML/CSS/JS puro em [`index.html`](index.html)
- Backend: Firebase (Auth com Google + Firestore)
- Acesso restrito por login Google + regras de segurança do Firestore

## Deploy

Publicado automaticamente via GitHub Pages a partir da branch `main`.

## Desenvolvimento local

Basta abrir `index.html` no navegador. Em `localhost`/`127.0.0.1`/`file://`
um botão de bypass de login aparece para facilitar testes.
